Two things to set (not code)

a) Firebase Anonymous sign-in must be ON. The app reads data as an anonymous user. If the app ever can't load vehicles, the Complete Sale screen will say "Could not load from server (permission-denied)" — that means Anonymous auth is off. Turn it on: Firebase console → Authentication → Sign-in method → Anonymous → Enable.

b) Google review link. The thank-you email has a placeholder [PASTE GOOGLE REVIEW LINK]. Send me the real Auto Capital review URL and I'll set it, or edit CE_GOOGLE_REVIEW_LINK in index.html.

Known limitation

Push notifications when the app is closed need server-side push (not set up). In-app banners fire while the app is open — fine for the demo.
